## Examples

In this folder there are several examples of using the library, both for method comparison and for real world applications. The folder is structured as follows:

- **01_demos**: The README examples in a format that can be easily run.
- **02_method_comparison**: Notebooks comparing the inference methods for the Ising and Potts models.
- **03_msa**: Protein contact prediction (DCA) on the Kunitz domain family (Pfam PF00014). Note: the full PLE fit takes about 50 minutes on a CPU.
- **04_neural_spikes**: Inferring couplings from (synthetic) neural spike data, and the effect of the bin width.
